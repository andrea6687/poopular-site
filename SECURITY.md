# Security Policy

🇮🇹 Italiano più sotto.

## Reporting a vulnerability

Please **don't open a public issue** for security problems.

Use GitHub's private reporting instead: go to the [Security tab](https://github.com/andrea6687/poopular-site/security) and choose **Report a vulnerability**. You'll get an answer as soon as possible, usually within a week.

Do not include your entries (dates, times, characters) in the report.

Examples of what to report:

- a way for the published page to load third-party code or send data anywhere;
- a change that would collect the entries the page says stay on the iPhone and the Apple Watch;
- anything that exposes someone else's private information through an issue or the page.

## Supported versions

Only the latest version on the `main` branch is supported. GitHub Pages publishes that branch from the repository root.

## What the page does and doesn't do

- [`index.html`](index.html) is a static page. It has no scripts, no forms, and no server of its own.
- The only link goes to this repository's [issues](https://github.com/andrea6687/poopular-site/issues).
- You can read the whole page in `index.html` before trusting it.

## Italiano

Per i problemi di sicurezza **non aprire una issue pubblica**: usa la [scheda Security](https://github.com/andrea6687/poopular-site/security) → **Report a vulnerability**, che è privata. Non includere i tuoi segni (date, orari, personaggi).

È supportata solo l'ultima versione su `main`, ed è quella che GitHub Pages pubblica dalla radice del repository. [`index.html`](index.html) è una pagina statica: niente script, niente moduli, niente server. L'unico link porta alle [issue](https://github.com/andrea6687/poopular-site/issues) di questo repository. Il testo completo è in `index.html`: puoi leggerlo prima di fidarti.
